README.md — Apple Axiom
Твой интерактивный ИИ-питомец и системный ассистент для экосистемы Apple с кроссплатформенным ядром Kotlin Multiplatform и мультиагентной архитектурой.


💡 О проекте
Apple Technik — это концептуальный проект, объединяющий функционал глубокого системного мониторинга устройств Apple (iOS / macOS), предиктивной диагностики «железа» и эмоционального тамагочи-компаньона.

Вместо скучных всплывающих окон с предупреждениями об ошибках за состоянием твоего Mac или iPhone следит живой робот-питомец. Если устройство перегревается, забивается кэшем или изнашивается аккумулятор — робот меняет свое настроение, «кашляет», привлекает внимание через Dynamic Island или Menu Bar и предлагает интерактивные решения по оптимизации.


🤖 Архитектура ИИ (Groq + OpenRouter)
Диспетчер агентов передает запросы совместимым с OpenAI chat-completions API провайдерам:

Локальные сенсоры (Kotlin / Swift): Тихий сбор метрик (температура, износ батареи, свободное место, обороты кулера).
Диспетчер событий: Упаковка аномалий в компактные JSON-логи.
Команда ИИ-Агентов:
The Medic (Диагност): Анализирует JSON-логи через Groq и определяет вероятные технические причины.
The Companion (Коммуникатор): Переводит диагноз на эмоциональный язык питомца через OpenRouter.
The Fixer (Оптимизатор): Предлагает пошаговые сценарии самоисправления через OpenRouter.


🛠 Технологический стек
Ядро: Kotlin Multiplatform (KMP) для кроссплатформенной бизнес-логики.
Интерфейс (UI/UX): SwiftUI, нативные виджеты, Menu Bar App, Dynamic Island & Live Activities.
Интеллект: Groq для диагностики и OpenRouter для коммуникации и сценариев оптимизации.

### Проверка цепочки агентов

JVM-раннер отправляет четыре тестовых сценария (норма, перегрев, износ батареи и нехватка места) через Medic, Companion и Fixer. Перед запуском задайте `GROQ_API_KEY` и один из `OPENROUTER_API_KEY`, `OPENROUTER_API_KEY_1` или `OPENROUTER_API_KEY_2`, затем выполните `./gradlew runAgentSimulator`.
